# Eligibility Rules Specification

## Hard Disqualifiers
- Property type = Agricultural
- Original documents unavailable
- Income mode = Cash
- Tenure < 3 or > 15 years

## Soft Fail (Counter-Offer)
- Loan amount > ₹75,00,000 → offer ₹75L cap

## Never Fails
- Ownership (Sole or Joint)
- Market value (capture only)
